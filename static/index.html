Syarat & Ketentuan Penggunaan Whenyhh.ai

1. Perlindungan Data Pribadi (UU PDP No. 27/2022)

Aplikasi ini berjalan sepenuhnya di perangkat lokal Anda. Tidak ada data skenario, narasi, atau identitas pengguna yang dikirim ke server eksternal tanpa izin Anda. Jika Anda mengaktifkan penyedia cloud (Groq, OpenRouter, atau lainnya), konten aksi dan narasi akan dikirim ke penyedia tersebut sesuai kebijakan privasi masing-masing.

2. Kunci API (SE Menkominfo No. 9/2023)

Kunci API yang Anda masukkan hanya disimpan di sessionStorage peramban dan hilang otomatis saat tab ditutup. Kunci tidak pernah disimpan di basis data, log server, atau dikirim ke pihak lain selain penyedia LLM yang Anda pilih.

3. Konten Simulasi & Disclaimer

  • Konten yang dihasilkan LLM bersifat fiksi dan tidak mencerminkan pandangan tim pengembang.
  • Jika simulasi menyinggung topik kesehatan jiwa, hubungi Hotline Healing119.id (119 ext. 8) atau konselor terdekat.
  • Untuk verifikasi rekening terduga penipuan, gunakan CekRekening.id (cekrekening.id) atau laporkan ke IASC OJK (ojk.go.id/id/kanal/iknb/laporan-dan-statistik/asuransi/Pages/IASC.aspx).

4. Batasan Penggunaan

Aplikasi ini ditujukan untuk keperluan edukasi, penelitian, dan kreasi konten fiksi. Dilarang menggunakannya untuk membuat konten yang melanggar hukum, menyebarkan disinformasi, atau merugikan pihak lain.
